# Traveloop Design System

## Colors

- **Primary**: HSL 221.2 83.2% 53.3% (Royal Blue)
- **Secondary**: HSL 210 40% 96.1% (Soft Gray-Blue)
- **Background**: HSL 0 0% 100% (White)
- **Foreground**: HSL 222.2 84% 4.9% (Very Dark Blue)
- **Destructive**: HSL 0 84.2% 60.2% (Soft Red)

## Typography

- **Font Family**: Inter, sans-serif
- **Headings**: Bold, tight letter spacing
- **Body**: Regular, readable line height

## UI Elements

- **Buttons**: Rounded corners (0.5rem), hover effects with opacity or slight translation
- **Cards**: Soft shadows, rounded borders (1rem)
- **Inputs**: Solid borders, focus ring in primary color

## Animations & Magic UI

- **Reveal**: BlurFade for hero sections.
- **Micro-interactions**: Hover scaling on cards.

## Anti-patterns

- No inline styles.
- No unsemantic HTML elements for interaction (use buttons).
- Avoid overly saturated colors outside of the primary action.
